# Design instructions for AI coding agents

For Codex, Gemini CLI, Windsurf, Copilot agents and any tool that reads AGENTS.md.

When you build or change any UI (website, web app, mobile, desktop):

1. Follow `skills/design-workflow/SKILL.md`: Direction, Build, Test, Review. Propose 3 directions before building.
2. Apply `skills/apple-design-universal/SKILL.md` for foundations: 4px spacing scale, semantic color tokens, 4.5:1 text contrast, 44px touch targets, dark mode, reduced motion, semantic HTML, every interactive state.
3. Run the final checklist in `apple-design-universal` and fix every failure before saying done.
4. Keep chat answers short. Put detail in files. The user's brand and instructions win; mention conflicts in one line.
5. Never copy another brand's logo, name or assets. Never invent stats or testimonials.
6. Test at 375, 768 and 1280px in light and dark mode. Liquid Glass only on control surfaces, never glass on glass, with a reduced-transparency fallback.
