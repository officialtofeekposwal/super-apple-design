# 📋 Phase 1 Design Brief Generator

> **Interactive Questionnaire to establish crystal-clear direction before writing code**

Copy and paste this questionnaire into your agent chat when kicking off a new project or major feature:

```markdown
I want to establish the Phase 1 Design Brief for my project. Please answer these 5 questions based on my domain:

1. Target Domain & User Persona:
   - What is the product (e.g. Fintech dashboard, Habit tracker, Agency portfolio, DevTool)?
   - What is the desired visual density (Spacious/Airy vs Dense/Compact)?

2. 3 Contrasting Directions:
   - Present 3 distinct, high-conviction creative concepts:
     * Direction A: Restrained Cupertino Monochrome
     * Direction B: Luminescent Editorial Vibrancy
     * Direction C: Neo-visionOS Spatial Depth

3. Locked Token Choices:
   - Primary Accent Tint (e.g. System Blue #007AFF, Purple #AF52DE, Emerald #34C759)
   - Continuous Squircle Radius Scale (Small: 10px, Medium: 14px, Large: 20px, XL: 28px)
   - Font family cascade and optical tracking rules

4. Core Interactive Controls:
   - What is the single primary call-to-action on this screen?
   - What navigation pattern fits best (Collapsible Top Navbar, Bottom Tab Bar, Floating Dock)?

5. Confirmation Gate:
   - Do not write code yet. Present your recommendation and await my direction confirmation.
```
